// modules --soc
Two engines behind one dashboard. Both return the same verdict scale, so an analyst reads phishing submissions and indicator lookups the same way.
🎣 Module A — Phishing Portal
MINE
.eml intake — paste or upload a suspicious email
Headers — SPF, DKIM, DMARC, From / Reply-To, originating IP
URLs — defanging, shorteners, lookalike domains, reputation
Attachments — MD5 / SHA-256, dangerous extensions
Triage queue — submissions sorted by risk score
🔍 Module B — IOC Lookup
TEAMMATE
Auto-detect — IP / domain / URL / hash
Multi-source — VirusTotal, AbuseIPDB, URLhaus, MalwareBazaar, WHOIS
Aggregation — many sources into one verdict
Caching — respects third-party API quotas
History + export — search log, CSV / blocklist export
SHARED FOUNDATION
JWT auth Analyst / admin roles Unified dashboard OpenAPI docs PostgreSQL + Alembic Dockerized DB
// triage --verdict
