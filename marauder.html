Marauder

LINUX PRIVESC · IN DEVELOPMENT
Aperit Semitas — it opens the paths.
A lightweight, single-binary enumeration tool for Linux post-exploitation, written in Go. Once you have a foothold on a host — in an authorized engagement or a CTF — it maps the system like a Marauder's Map for a box and reveals local privilege-escalation paths and useful secrets. It enumerates and reports; it does not exploit anything.

// modules --the-map
Run marauder with no arguments for the full map, or one module at a time — each named for what it does.
revelio · reveal
System enumeration — OS and kernel version, users and groups, high-UID accounts, environment and PATH, mounts and fstab credentials.
alohomora · unlock
Privilege-escalation paths — SUID / SGID binaries, sudo rules and misconfigurations, cron jobs, writable service paths, world-writable files.
niffler · dig
Secret hunting — SSH private keys, shell history, credentials in config files and other interesting files left on the box.
// design --goals
Lands clean
One static binary, no runtime dependencies on the target — drop it, run it, read the map. A stripped CGO_ENABLED=0 build has no libc dependency.
Native collection
Standard library where possible, reading the system in Go rather than shelling out — a smaller, quieter footprint on the host.
Clean output
Human-readable now; the banner prints to stderr and is suppressed by --quiet or --json, so it never pollutes a pipe. Machine-readable JSON is planned.
Authorized use only
An assessment tool for systems you own or are authorized to test — CTFs, labs, authorized engagements. It reports; it never exploits.
// roadmap
A learning project — built to go deep on Linux privilege-escalation enumeration, and to learn Go from the ground up. Checks are added incrementally.
