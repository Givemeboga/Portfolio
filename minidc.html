// network --core
A real campus design, shrunk to containers: redundant everything, one out-of-band management network, and OSPF carrying the whole fabric.
Edge
Two ISPs NAT to the real Internet; two FRR edge routers do NAT and port-forwards, each announcing a default route in OSPF (cost 10 / 20).
Core
Two Arista cEOS L3 cores — VRRP load sharing on the gateways, a 2×10G LACP bundle between them, MSTP (one root per VLAN group), OSPF.
Access
Two cEOS top-of-rack switches, dual-homed to both cores; servers behind keepalived virtual IPs; an isolated, non-routed SAN segment.
// resilience --measured
Every redundancy claim is backed by a drill — cut a device, time the recovery, confirm nothing is lost.
ISP failover · ≈0.2 s
Each edge announces its default route in OSPF (cost 10 / 20); losing the primary reroutes through the backup.
Firewall failover · ≈0.2 s
fw-01 isolated → BFD + OSPF reroute through fw-02, the DMZ gateway moves, open connections kept via conntrackd.
Database failover · ≈0.6 s
MariaDB replication + a keepalived virtual IP; no data lost on either a crash or a clean server-offline.
Website / intranet · ≈0.8 s
A cut DMZ or rack server; the virtual IP for www.dc.lab / intranet moves to its pair in the other rack.
Gateway (VRRP) · ≈2.8 s
A core lost; servers keep their .1 gateway as VRRP fails over to the surviving core.
DNS failover · ≈40 ms
dns01 stopped → the secondary answers; backups run nightly with an automatic restore test (row counts match).
// security --defense-in-depth
Firewall pair · default drop
Two nftables firewalls (fw-02 standby), plus a host firewall on every server — allowed and forbidden flows checked rule by rule.
Suricata IDS · auto-block
Intrusion detection at the edges with automatic blocking, exercised against a Kali attacker in the demo.
TLS everywhere · RADIUS
HTTPS, MariaDB TLS, Zabbix PSK and SNMPv3 inside the lab; switch logins via RADIUS; no secrets in git.
Isolated SAN
A non-routed storage segment: each server reaches only its own iSCSI LUN, ACL'd per initiator — another server's LUN is denied.
// storage-and-ops
TrueNAS iSCSI SAN
TrueNAS SCALE 25.10 as a KVM VM inside the lab — a ZFS mirror serving one iSCSI LUN per server with per-initiator ACLs.
Backups + restore test
A nightly job on backup01: database and switch configs, checksums, 7 restore points, a copy on TrueNAS (ZFS snapshots) and an automatic restore test.
Zabbix 7 NOC
Set up automatically — agents on every server and firewall, data-center checks, alarms and a dashboard; every device logs to two collectors over syslog, with NTP.
Buildings & power
Two technical buildings modelled for the design (2N power, UPS, generators, N+1 cooling, fire suppression, access control) — the non-emulated physical layer around the fabric.
